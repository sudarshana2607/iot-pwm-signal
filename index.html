Intro

Pulse Width Modulation (PWM) controls the average power delivered to a load by switching a digital signal between LOW and HIGH and changing how long it stays HIGH during each period.

Why it mattersArduino pins are digital outputs, but PWM lets us control perceived LED brightness and the speed of suitable DC motors without producing a true continuously variable voltage.
By the end, you canDefine duty cycle and frequency, read a PWM waveform, wire an LED safely, change brightness using Arduino, calculate ON time, and troubleshoot common issues.
PrerequisitesVoltage, current, digital HIGH/LOW, Ohm’s law, basic Arduino pin and sketch concepts.
Key vocabularyPeriod (T), frequency (f), duty cycle (D), pulse width (tON), LOW time (tOFF), PWM-capable pin, `analogWrite()`.

Important distinction: On a classic Arduino Uno, `analogWrite(pin, value)` usually accepts a value from 0 to 255. It generates PWM on supported pins; it does not output a true analog voltage. PWM frequency depends on the board and pin/timer configuration.

Principle

  1. Arduino’s timer hardware repeatedly creates a digital pulse on a PWM-capable output.
  2. The signal alternates between LOW (approximately 0 V) and HIGH (approximately the board’s logic voltage, often 5 V on a classic Uno).
  3. The duty cycle sets the percentage of each period spent HIGH.
  4. The LED responds to the average current/light over time, so a higher duty cycle generally appears brighter to our eyes.
  5. For a motor, PWM rapidly switches power; motor inductance and mechanical inertia smooth the response. A driver stage is normally required.
DC viewAt 0% the pin is LOW; at 100% it is HIGH. Intermediate values are rapid switching, not a steady intermediate voltage.
Time-domain viewFrequency determines how often pulses repeat. Duty cycle determines the HIGH fraction of each period.

Operating assumptions

  • For simple calculations, assume ideal 0 V LOW and 5 V HIGH.
  • Assume a fixed PWM frequency when comparing duty cycles.
  • Actual board voltage, PWM frequency, timer setup, load and LED response can differ.

Advantages and limitations

AdvantagesLimitations
Efficient power control; simple digital control; easy to generate with timers; useful for LEDs and motors.Switching can cause EMI; output is not true analog DC; timer pins share hardware resources; load drivers and filtering may be needed.
Common misconception: `analogWrite(9, 128)` does not mean the pin continuously outputs 2.5 V. On a classic Uno it produces a PWM waveform with a duty cycle near 50% (128/255 ≈ 50.2%), subject to board implementation.

Code

This sketch gradually increases and decreases LED brightness using PWM on pin 9. Use a series resistor with the LED.

Arduino IDE sketch
const int ledPin = 9;  // PWM-capable pin on Arduino Uno

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // Fade from OFF to full brightness
  for (int value = 0; value <= 255; value++) {
    analogWrite(ledPin, value);
    delay(10);
  }

  // Fade from full brightness to OFF
  for (int value = 255; value >= 0; value--) {
    analogWrite(ledPin, value);
    delay(10);
  }
}

How the code works

  • `ledPin = 9` selects a PWM-capable output on a classic Uno.
  • `pinMode()` configures the pin as an output.
  • `analogWrite()` sets the PWM command from 0 to 255.
  • `delay(10)` makes each step visible; the PWM signal itself is generated by hardware while the program continues.
Experiment idea: Replace the fade loops with `analogWrite(ledPin, 64)`, then 128, 192 and 255. Record how the perceived brightness changes. Do not expect brightness to look perfectly linear to the eye.

What to observe

  • Increasing duty cycle keeps the output HIGH for a larger fraction of each period.
  • At 50%, HIGH and LOW times are equal.
  • At 0%, the signal remains LOW; at 100%, it remains HIGH, so regular pulses disappear at these endpoints.

Equations

Core equations

T = tON + tOFF

T = period in seconds; tON = HIGH time in seconds; tOFF = LOW time in seconds.

f = 1 / T

f = frequency in hertz (Hz), and T is in seconds. Higher frequency means a shorter period.

D = (tON / T) × 100%

D = duty cycle. Use the same time units in the ratio.

tON = (D / 100) × T    ;    tOFF = T − tON
Vavg ≈ Dfraction × VH

For ideal PWM switching between 0 V and a HIGH level VH, the average over one period is the duty fraction multiplied by VH. This describes the mathematical average, not necessarily the instantaneous pin voltage or a true analog output.

Derivation of average voltage

During tON, voltage is VH; during tOFF, voltage is 0 V. The average over one period is the time-weighted mean:

Vavg = [VH × tON + 0 × tOFF] / T
Vavg = VH × (tON / T) = VH × Dfraction

Arduino Uno mapping (classic 8-bit `analogWrite`)

analogWrite(pin, value), value = 0…255
Approximate duty fraction ≈ value / 255

This approximation is useful for basic calculations; exact timer behavior and frequency are board- and core-dependent. Values 0 and 255 are normally fully LOW and fully HIGH respectively.

Solved

Example 1 — Find duty cycle (Easy)

Given: Period T = 4 ms; HIGH time = 1 ms. Find: Duty cycle.

Formula: D = (tON/T) × 100%

D = (1 ms / 4 ms) × 100% = 25%

Interpretation: The signal is HIGH for one-quarter of each cycle.

Example 2 — Find ON and OFF time (Moderate)

Given: f = 1 kHz and D = 60%. Find: Period, ON time and OFF time.

T = 1/f = 1/1000 s = 1 ms
tON = 0.60 × 1 ms = 0.60 ms
tOFF = 1.00 − 0.60 = 0.40 ms

Interpretation: Each 1 ms cycle is HIGH for 0.6 ms and LOW for 0.4 ms.

Example 3 — Ideal average voltage (GATE-style, Moderate)

Given: Ideal PWM swings between 0 V and 5 V with duty cycle 40%. Find: Average voltage.

Vavg = Dfraction × VH = 0.40 × 5 V = 2.0 V

Answer: 2.0 V average in the ideal mathematical sense. The actual pin still switches between LOW and HIGH.

Example 4 — Arduino value (Difficult)

Given: Classic 8-bit `analogWrite()` and value = 192. Estimate the duty cycle and ideal average voltage for a 5 V HIGH level.

D ≈ (192 / 255) × 100% ≈ 75.3%
Vavg ≈ (192 / 255) × 5 V ≈ 3.76 V

Interpretation: The waveform is HIGH for about three-quarters of each cycle. Do not describe 3.76 V as the instantaneous pin output.

EXAM FOCUS

GATE

For PWM questions, first identify the period and duty cycle, then use the reciprocal frequency relation and time-weighted average.

High-priority concepts
  • Frequency and period: f = 1/T.
  • Duty cycle: D = tON/T × 100%.
  • For ideal 0-to-VH PWM, Vavg = Dfraction × VH.
  • Duty cycle and frequency are different quantities.
Exam approach
  • Convert milliseconds to seconds before calculating frequency.
  • Keep duty cycle as a fraction when using average-voltage equations.
  • Distinguish instantaneous HIGH/LOW levels from average voltage.
  • Check whether the question assumes fixed frequency.
Common trap: A 50% duty-cycle signal switching between 0 V and 5 V has an ideal average of 2.5 V, but it does not stay continuously at 2.5 V.

GATE Quiz

Interview

Expand each question to review a concise answer. Try saying the answer aloud before opening it.

1. What is PWM?

PWM is a method of controlling average power by switching a digital signal and varying the fraction of each period it remains HIGH.

2. What is duty cycle?

Duty cycle is the ratio of HIGH time to total period, usually expressed as a percentage: D = tON/T × 100%.

3. Does Arduino `analogWrite()` create a true analog voltage?

No. On common Arduino boards it generates PWM on supported pins. A filter or a suitable DAC is needed for a smoother analog voltage.

4. What is the relationship between frequency and period?

They are reciprocals: f = 1/T. If frequency rises, period falls.

5. Why is a resistor required with an LED?

It limits current to a safe value and protects the LED and GPIO pin from excessive current.

6. How would you measure PWM duty cycle in a lab?

Use an oscilloscope or logic analyzer to measure tON and T, then calculate D = tON/T × 100%.

7. The LED does not change brightness. What would you check?

Check LED polarity, resistor and GND wiring, selected PWM pin, uploaded sketch, pin number, and whether the simulator supports the selected board.

8. Why should a motor not be connected directly to an Arduino GPIO?

A motor can draw more current than the pin can safely supply and can generate inductive voltage spikes. Use a suitable driver and protection circuit.

9. Why might two PWM pins have different frequencies?

Different pins may be driven by different timer peripherals or timer configurations. The exact mapping depends on the board and core.

10. How can PWM control a DC motor?

A driver switches motor power in pulses. Duty cycle adjusts average applied voltage/power, influencing speed under the given load. Direction control usually requires a suitable H-bridge.

11. What causes PWM-related electromagnetic interference?

Fast switching edges and current loops can radiate or conduct noise. Good grounding, short loops, decoupling, suitable switching frequency and filtering can help.

12. What is the difference between PWM and DAC output?

PWM encodes a value as pulse timing; a DAC converts a digital code into an analog level. Filtering PWM can approximate an analog level, but ripple and response time remain.

Industry perspective

PWM is used in LED dimmers, fan and motor control, power converters, heater control and embedded products. Engineers must consider switching losses, ripple, audible noise, EMI, timer resolution, thermal limits, load-driver ratings and safety validation.

Revision

  • Period: T = tON + tOFF (seconds).
  • Frequency: f = 1/T (Hz).
  • Duty cycle: D = (tON/T) × 100%.
  • ON time: tON = (D/100) × T.
  • OFF time: tOFF = T − tON.
  • Ideal average: Vavg ≈ Dfraction × VH for a 0-to-VH waveform.
  • Classic Uno PWM command: `analogWrite(pin, value)`, value typically 0–255 on supported pins.

High-priority points

  • Duty cycle controls the HIGH-time fraction; frequency controls how often pulses repeat.
  • PWM is digital switching, not a true analog output.
  • At 50% duty, tON = tOFF = T/2.
  • Always use a current-limiting resistor with a simple LED circuit.
  • Use a driver for motors and other loads that need more current than a GPIO can safely provide.
  • Board families differ: confirm PWM pins, voltage levels, resolution and frequency for your exact Arduino.
